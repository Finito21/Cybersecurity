# Tools

The tools from the notes, each described from a practical angle: what it is for, how to start and how it fits into the methodology.

| Tool | Use |
|---|---|
| [Burp Suite](burp_suite.md) | intercepting and modifying HTTP traffic, manual web application testing |
| [ZAP](zap.md) | a free proxy with active and passive scanning |

!!! tip "Where to start"
    To begin, **Burp Suite Community** and a browser with a proxy are enough. ZAP is a good free alternative when a scanner helps. Reconnaissance, before you touch the application, has its own section: [OSINT](../osint/index.md).

!!! warning "Only with permission"
    The techniques described here are used only on your own systems, in a lab or with the owner's written permission, within the agreed scope.
